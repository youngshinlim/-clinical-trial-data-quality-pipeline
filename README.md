# Clinical Trial Data Quality & Reporting Pipeline

An independent Python project simulating clinical data management workflows in early-phase clinical trials.

## Objectives
- Validate multi-site clinical laboratory datasets
- Identify missing, duplicate, and inconsistent records
- Flag laboratory results requiring further review
- Automate Excel-based data quality reporting
- Visualize trends in clinical data completeness

## Technologies
Python, pandas, NumPy, Matplotlib, openpyxl

## Data
All study records are synthetic and created solely for educational and portfolio purposes.
